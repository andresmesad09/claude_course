second_brain

Got a thought? Type it in your terminal and it becomes a plain markdown note you can find and read again later.

✍️

new TEXT

second_brain new [OPTIONS] TEXT

Save a quick thought. Wrap it in quotes so the whole sentence counts as one TEXT.

  • exit 0Prints Saved /path/to/the/note.md
  • exit 2Empty or blank text: A note can't be empty.
  • exit 2Forgot the quotes, so the extra words become unexpected extra arguments.
🛡️ Never overwrites. If two notes get the same name in the same second, the second one becomes …-2.md.
📋

list

second_brain list [OPTIONS]

Shows the full path of your notes folder and a numbered list of notes, newest first. Those numbers are what show uses.

  • exit 0Notes in /…/second_brain: followed by 1. …, 2. …
  • exit 0No notes yet? It says No notes yet. and doesn't create the folder.
🙈 Only *.md files directly in the folder count. Hidden files like .DS_Store and subfolders are skipped.
👀

show NUMBER

second_brain show [OPTIONS] NUMBER

Prints one note exactly as it's stored. Get the number from list, or click a note in the folder.

Try a mistake:
  • exit 0The note's markdown, nothing else, so you can pipe it.
  • exit 2No such note: No note #9. You have 3 notes.
  • exit 20 or a non-number is rejected by Click itself.
📋 Copy a note to the clipboard on macOS: second_brain show 1 | pbcopy. Numbers shift when you add a note, so run list again if you're unsure.

Stuck? Every command explains itself. Click to ask:

    🎛️Settings and exit codes
    
    
    Set these in your shell or in a .env file in the folder you run the command from. Values already set in your shell win over .env.
    
    
    
      
    📁
    SECOND_BRAIN_DIR
    Where notes are saved. Default ~/second_brain. Created on the first new.
    
      
    🔊
    LOG_LEVEL
    How chatty the terminal logs are. Default INFO. Try DEBUG.
    
      
    📜
    LOG_FILE
    Where the detailed log goes. Default app.log, rotated at 50 KB.
    
    
    
    
    
      
    ✅
    exit 0
    It worked: saved, listed, shown, or help you asked for.
    
      
    ⚠️
    exit 2
    Something in the command is off. The message tells you what.
    
      
    💥
    exit 1
    Something unexpected broke. The full traceback is written to the log.
